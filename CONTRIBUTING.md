# Contributing to SystemVitals

Thanks for contributing. Please open a focused issue before substantial work and keep each pull request focused on one change.

## Pull requests

- Add or update tests for behavior changes.
- Update documentation when behavior, configuration, or deployment changes.
- Never include production data, credentials, private keys, or populated `.env` files.
- Use conventional commit subjects, for example `feat: add TCP probe timeout` or `fix: preserve paused checks during a sweep`.

Run the relevant project validation commands before requesting review. Describe the user-visible change, tests run, and any follow-up work in the pull request.
