# Support

For usage questions, configuration help, and ideas, start a discussion in [GitHub Discussions](https://github.com/SystemVitals/systemvitals/discussions).

For reproducible product bugs, use the [bug report issue template](https://github.com/SystemVitals/systemvitals/issues/new/choose).

For undisclosed security vulnerabilities, follow the private process in [SECURITY.md](SECURITY.md) instead of opening an issue.
